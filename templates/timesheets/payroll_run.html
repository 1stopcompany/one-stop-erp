How this page works

Review and adjust each employee below: base pay and the unpaid-leave deduction can be typed over the automatic figure (a typed figure is marked manual; set it back to the automatic value to return to automatic), as can overtime, allowances, deductions and advances. Click Save on a row to recalculate it. The button takes an employee out of this month's run (they are not posted or paid; restore them from the list below), and an employee who is not in the run can be added by hand. Tax is shown for information only and is not subtracted from net pay. Once everything looks right, click Post Payroll to finalize this month -- posted payslips are locked and can no longer be edited here.
